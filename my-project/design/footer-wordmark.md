# ASCII footer signature

Reference: https://asciify.org/, inspected October 22, 2026 at 1440 × 1000. The footer uses a static poster followed by a lazy-loaded Asciify glyph-field canvas. Its original word is `asciify`, set in Fraunces Semibold, with Geist glyphs and no hover interaction.

## Adaptation

The shared `partials/footer-wordmark.html` appears after the copyright footer on Home and Start, not on article pages. The custom text is `TechMind`, with uppercase T and M. Its width follows each page's existing content gutters. Its ink follows the site's light/dark palette; no fixed black panel is added.

The original MIT-licensed browser renderer is reused without modifying its compiled code. `javascripts/footer-wordmark.js` provides lazy loading, local font loading, responsive cell sizing, palette updates, and cleanup for MkDocs instant navigation. No reference-site application, analytics, or server APIs are included. The original site's pointer motion comes from a separate global `cursorTrail` layer, not the footer's `hover: none` wordmark setting. Its trail implementation is extracted into `cursor-trail.js` with only its required imports. This site enables it over the wordmark only, clips it to that area, and disables it on touch/reduced-motion devices.

The renderer's 1800 × 520 source mask uses a 379.464px Fraunces Semibold font for this eight-character word. The scoped font face has `size-adjust: 90%` because capital T/M would otherwise exceed the source renderer's fixed mask width. Its measured ink bounds are x=81…1718, y=125…383. The viewport includes a five-pixel safety inset: x=76, y=120, width=1648, height=269. The live canvas and the static SVG use this same crop. The SVG was generated by sampling this text mask into an ASCII character ramp, not by stretching the source site's image.

Reduced-motion users and browsers without a supported renderer retain the local static poster. The poster is also available before JavaScript and while the lazy module/fonts load. The decorative canvas is hidden from assistive technology.
