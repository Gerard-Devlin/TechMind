??? question "为什么先把正则表达式变成 NFA？"

    因为正则表达式里经常有“多种可能”。$a(b|c)^*$
    
    - $(b|c)$：可以选 $b$，也可以选 $c$
    - $^*$：可以重复任意多次
    
    NFA 很适合表示这种“不确定选择”。一个状态读入字符后，可以同时有多个可能的下一状态。

??? question "为什么还要把 NFA 变成 DFA？"

    NFA 运行时可能需要同时记录多个状态. $\delta(q_0,a)={q_0,q_1}$ ，表示读入 $a$ 后，可能在 $q_0$，也可能在 $q_1$。
    
    DFA 会把这一组状态 $\{q_0,q_1\}$ 整体当成一个新的状态，例如记为 $B$ ，于是 $B=\{q_0,q_1\}$
    
    这样 DFA 每次读入一个字符后，只需要进入一个确定的状态，执行起来更方便。这种方法叫作**子集构造法**。

## 一、$Thompson$ 算法

- 把正则表达式拆成最小结构，每种结构都有固定的 NFA 模板拼起来

| 正则结构           | 构造方法                                          |
| ------------------ | ------------------------------------------------- |
| 单个字符 $a$       | 建立两个状态，中间用 $a$ 连接                     |
| 空串 $\varepsilon$ | 建立两个状态，中间用 $\varepsilon$ 连接           |
| 连接 $e_1e_2$      | 用 $\varepsilon$ 连接 $e_1$ 的终点和 $e_2$ 的起点 |
| 选择 $e_1\mid e_2$ | 增加新起点和新终点，用 $\varepsilon$ 分叉和汇合   |
| 闭包 $e^*$         | 增加跳过、进入、重复和退出的 $\varepsilon$ 转移   |

## 二、子集构造算法

NFA 读入一个字符后，可能同时处于多个状态，$\delta(q_0,a)=\{q_0,q_1\}$

DFA 不允许同时处于多个状态，所以把这一组 NFA 状态  $\{q_0,q_1\}$ 整体当作 DFA 的一个状态。因此，$\boxed{\text{DFA 的一个状态 = NFA 的一个状态子集}}$ ，这就是“子集构造”的来源

### 1、步骤

假设 NFA 的初始状态是 $q_0$

DFA 的初始状态不是简单的 $\{q_0\}$，而是 $D_0=\varepsilon\text{-closure}({q_0})$ ，也就是先把所有能通过空转移到达的状态都找出来。

对于当前 DFA 状态 $T$，读入字符 $a$ 后的新状态为
$$
U=
\varepsilon\text{-closure}
\left(
\operatorname{move}(T,a)
\right)
$$
如果 $U$ 之前没有出现过，就把它加入 DFA 状态集合。不断重复，直到没有新的状态集合产生。

如果一个 DFA 状态集合中包含任意 NFA 接受状态，那么它就是 DFA 的接受状态。
$$
T\cap F_{\text{NFA}}\neq\varnothing
$$
则 $T$ 是 DFA 接受状态。

---

!!! example

    ```mermaid
    flowchart LR
        start(( )) --> q0((0))
        q0 -->|a| q1((1))
        q1 -->|ε| q2((2))

        q2 -->|ε| q3((3))
        q2 -->|ε| q9(((9)))

        q3 -->|ε| q4((4))
        q3 -->|ε| q6((6))

        q4 -->|b| q5((5))
        q6 -->|c| q7((7))

        q5 -->|ε| q8((8))
        q7 -->|ε| q8

        q8 -->|ε| q3
        q8 -->|ε| q9
    ```

    原 NFA 的初始状态为 $n_0$，终结状态为 $n_9$，输入字母表为 $\Sigma={a,b,c}$。子集构造时，每次计算都遵循
    $$
    \delta_{\mathrm{DFA}}(D_i,x)=\varepsilon\text{-closure}\left(\operatorname{move}(D_i,x)\right)
    $$
    **先读入字符 $x$，再把所有能够通过 $\varepsilon$ 边到达的状态加入集合**

    - 构造初始状态 $D_0$

    初始 DFA 状态为 $D_0=\varepsilon\text{-closure}({n_0})={n_0}$，因为 $n_0$ 没有 $\varepsilon$ 转移。

    从 $n_0$ 读入 $a$，有 $n_0\xrightarrow{a}n_1$，所以先得到 $\operatorname{move}(D_0,a)={n_1}$。但是还不能停止，因为还要从 $n_1$ 继续沿着所有 $\varepsilon$ 边移动。

    从 $n_1$ 可以通过 $\varepsilon$ 到达 $n_2$，从 $n_2$ 可以到达 $n_3$ 和 $n_9$，从 $n_3$ 又可以到达 $n_4$ 和 $n_6$，因此：

    $$
    D_1=\varepsilon\text{-closure}({n_1})={n_1,n_2,n_3,n_4,n_6,n_9}
    $$

    所以 DFA 中有 $D_0\xrightarrow{a}D_1$。从 $D_0$ 读入 $b$ 或 $c$ 时，$n_0$ 都没有对应的转移，因此 $D_0\xrightarrow{b}\varnothing$，$D_0\xrightarrow{c}\varnothing$。

    ---

    - 处理状态 $D_1$

    当前状态集合为 $D_1={n_1,n_2,n_3,n_4,n_6,n_9}$。

    检查这些状态中哪些状态有字符 $b$ 的转移，只有 $n_4\xrightarrow{b}n_5$，所以 $\operatorname{move}(D_1,b)={n_5}$。从 $n_5$ 可以通过 $\varepsilon$ 到达 $n_8$，从 $n_8$ 可以到达 $n_3$ 和 $n_9$，从 $n_3$ 又可以到达 $n_4$ 和 $n_6$，因此：

    $$
    D_2=\varepsilon\text{-closure}({n_5})={n_3,n_4,n_5,n_6,n_8,n_9}
    $$

    所以 DFA 中有 $D_1\xrightarrow{b}D_2$。

    检查这些状态中哪些状态有字符 $c$ 的转移，只有 $n_6\xrightarrow{c}n_7$，所以 $\operatorname{move}(D_1,c)={n_7}$。从 $n_7$ 可以通过 $\varepsilon$ 到达 $n_8$，从 $n_8$ 可以到达 $n_3$ 和 $n_9$，从 $n_3$ 又可以到达 $n_4$ 和 $n_6$，因此：

    $$
    D_3=\varepsilon\text{-closure}({n_7})={n_3,n_4,n_6,n_7,n_8,n_9}
    $$

    所以 DFA 中有 $D_1\xrightarrow{c}D_3$。

    $D_1$ 中没有状态具有字符 $a$ 的转移，因此 $D_1\xrightarrow{a}\varnothing$。

    ---

    - 处理状态 $D_2$

    当前状态集合为 $D_2={n_3,n_4,n_5,n_6,n_8,n_9}$。

    从 $D_2$ 读入 $b$ 时，只有 $n_4\xrightarrow{b}n_5$，所以 $\operatorname{move}(D_2,b)={n_5}$。求 ${n_5}$ 的 $\varepsilon$-闭包后，仍然得到 $D_2$，因此 $D_2\xrightarrow{b}D_2$。

    从 $D_2$ 读入 $c$ 时，只有 $n_6\xrightarrow{c}n_7$，所以 $\operatorname{move}(D_2,c)={n_7}$。求 ${n_7}$ 的 $\varepsilon$-闭包后得到 $D_3$，因此 $D_2\xrightarrow{c}D_3$。

    $D_2$ 中没有状态具有字符 $a$ 的转移，因此 $D_2\xrightarrow{a}\varnothing$。

    ---

    - 处理状态 $D_3$

    当前状态集合为 $D_3={n_3,n_4,n_6,n_7,n_8,n_9}$。

    从 $D_3$ 读入 $b$ 时，只有 $n_4\xrightarrow{b}n_5$，求 ${n_5}$ 的 $\varepsilon$-闭包后得到 $D_2$，因此 $D_3\xrightarrow{b}D_2$。

    从 $D_3$ 读入 $c$ 时，只有 $n_6\xrightarrow{c}n_7$，求 ${n_7}$ 的 $\varepsilon$-闭包后仍然得到 $D_3$，因此 $D_3\xrightarrow{c}D_3$。

    $D_3$ 中没有状态具有字符 $a$ 的转移，因此 $D_3\xrightarrow{a}\varnothing$。

    ---

    - 处理死状态

    将空集记作死状态 $D_{\varnothing}=\varnothing$。死状态中没有任何 NFA 状态，因此读入任意字符后仍然是死状态，即 $D_{\varnothing}\xrightarrow{a}D_{\varnothing}$，$D_{\varnothing}\xrightarrow{b}D_{\varnothing}$，$D_{\varnothing}\xrightarrow{c}D_{\varnothing}$。

    | DFA 状态          | 对应的 NFA 状态集合         | 输入 $a$          | 输入 $b$          | 输入 $c$          | 是否为终结状态 |
    | ----------------- | --------------------------- | ----------------- | ----------------- | ----------------- | -------------- |
    | $D_0$             | ${n_0}$                     | $D_1$             | $D_{\varnothing}$ | $D_{\varnothing}$ | 否             |
    | $D_1$             | ${n_1,n_2,n_3,n_4,n_6,n_9}$ | $D_{\varnothing}$ | $D_2$             | $D_3$             | 是             |
    | $D_2$             | ${n_3,n_4,n_5,n_6,n_8,n_9}$ | $D_{\varnothing}$ | $D_2$             | $D_3$             | 是             |
    | $D_3$             | ${n_3,n_4,n_6,n_7,n_8,n_9}$ | $D_{\varnothing}$ | $D_2$             | $D_3$             | 是             |
    | $D_{\varnothing}$ | $\varnothing$               | $D_{\varnothing}$ | $D_{\varnothing}$ | $D_{\varnothing}$ | 否             |

    ```mermaid
    flowchart LR
        start(( )) --> D0((D0))

        D0 -->|a| D1(((D1)))
        D0 -->|b,c| X((∅))

        D1 -->|a| X
        D1 -->|b| D2(((D2)))
        D1 -->|c| D3(((D3)))

        D2 -->|a| X
        D2 -->|b| D2
        D2 -->|c| D3

        D3 -->|a| X
        D3 -->|b| D2
        D3 -->|c| D3

        X -->|a,b,c| X
    ```
