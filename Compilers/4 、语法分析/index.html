    一、上下文无关文法（CFG）🧀

    CFG（Context-Free Grammar）用来描述程序语言的语法结构。

    一个 CFG 通常写成 \(G=(V,T,P,S)\) ，其中 \(V\) 是非终结符集合，\(T\) 是终结符集合，\(P\) 是产生式集合，\(S\) 是开始符号。

    例如表达式文法：

    1
2
3
    E → E + T | T
T → T * F | F
F → (E) | id
    • \(E,T,F\) 是非终结符
    • +、*、(、)、id 是终结符
    • \(E\) 是开始符号
    • E → E + T 等是产生式

    比如我们选择 \(N\rightarrow s\)\(V\rightarrow e\)\(N\rightarrow t\)

    那么就得到 \(S \Rightarrow NVN \Rightarrow sVN \Rightarrow seN \Rightarrow set\)

    二、自顶向下分析🧀

    自顶向下就是从开始符号 \(S\) 出发，不断选择产生式，试图推导出输入串，也就是从语法树的根开始，往叶子构造。

E

    1、递归下降🧀

    递归下降是最直观的自顶向下分析。基本思想是每个非终结符写一个函数。

    例如

    1
2
    E → T + E | T
T → id

    可以想成

    1
2
3
4
5
6
7
8
    def E():
    T()
    if next_token == '+':
        match('+')
        E()

def T():
    match('id')

    也就是说：

    • 遇到非终结符 \(E\)，调用函数 E()
    • 遇到非终结符 \(T\)，调用函数 T()
    • 遇到终结符，就和当前输入 token 匹配

    所以 \(\boxed{\text{递归下降 = 用程序函数模拟文法推导}}\)

    它的问题是：如果一个非终结符有多个产生式，就必须决定选哪个。

    比如

    1
    A → aB | aC

    看到下一个字符 a 时，你不知道该选哪一个。

    因此普通递归下降有时需要回溯。

    另外，它不能直接处理左递归，例如

    1
    E → E + T | T

    因为函数 E() 一进来又调用 E()，会无限递归。

    所以通常需要消除左递归。

    2、LL 算法🧀

    LL 可以理解成更规范、更自动化的递归下降。

    LL 中两个 L 的含义：

    • 第一个 L：从左到右扫描输入
    • 第二个 L：构造最左推导 Leftmost Derivation

    LL(1) 中的 1 表示：

    只看前面 1 个 token，就能决定用哪个产生式。

    例如：

    1
    S → aA | bB

    如果看到下一个 token 是 a，直接选择：

    1
    S → aA

    如果看到 b：

    1
    S → bB

    不需要回溯。

    LL(1) 的关键工具就是：

    • FIRST 集
    • FOLLOW 集
    • LL(1) 分析表

    比如分析表可能长这样：

    非终结符 a b
    \(S\) \(S\to aA\) \(S\to bB\)

    分析时看：

    1
    当前栈顶非终结符 + 当前输入 token

    然后查表决定使用哪个产生式。

    所以：

    \(\boxed{\text{LL = 看输入前缀，预测应该使用哪条产生式}}\)

    因此 LL 也经常叫预测分析。

    递归下降和 LL 的关系可以理解成：

    递归下降是一种实现方式，LL 是一种更系统的自顶向下分析方法。

    很多 LL(1) 文法可以直接写成递归下降程序。

    三、自底向上分析🧀

    自底向上完全反过来。

    它不是从开始符号往下推，而是：

    从输入串出发，不断把已经识别出的部分归约成非终结符，最后得到开始符号。

    例如输入：

    1
    id + id

    如果文法：

    1
2
3
    E → E + T
E → T
T → id

    可以这样：

    1
2
3
4
5
6
7
8
9
    id + id
↓
T + id
↓
E + id
↓
E + T
↓
E

    最后整个输入被归约成开始符号 \(E\)，说明输入合法。

    所以：

    \(\boxed{\text{自底向上 = 从叶子往根构造语法树}}\)

    1、LR 算法🧀

    LR 是最重要的自底向上分析算法之一。

    两个字母含义是：

    • L：从左到右扫描输入
    • R：构造最右推导的逆过程

    LR 最核心的两个动作只有：

    Shift：移进🧀

    把下一个输入 token 放到栈里。

    比如：

    1
2
    栈：id
输入：+ id

    这就是 shift。

    Reduce：归约🧀

    如果栈顶的一部分符合某个产生式右边，就把它替换成左边。

    比如：

    1
    T → id

    那么栈顶出现：

    1
    id

    就可以归约成：

    1
    T

    即：

    1
    id  →  T

    再比如：

    1
    E → E + T

    如果栈顶出现：

    1
    E + T

    就可以整体归约成：

    1
    E

    所以 LR 的本质是不断：

    \(\boxed{\text{Shift → Shift → Reduce → Shift → Reduce ...}}\)

    直到：

    1
    accept
    对比 LL LR
    方向 自顶向下 自底向上
    从哪里开始 开始符号 输入串
    核心动作 预测使用哪个产生式 Shift / Reduce
    推导 最左推导 最右推导的逆
    左递归 通常不能直接处理 可以处理
    文法能力 较弱 更强
    实现 相对简单 相对复杂
    常见场景 手写 parser 编译器生成器
